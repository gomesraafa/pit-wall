# 🏎️ PIT WALL – GP DE SÃO PAULO

## Sobre o projeto

O Pit Wall é um projeto desenvolvido como atividade de estudo de HTML e CSS, inspirado no universo da Fórmula 1 e no Grande Prêmio de São Paulo, realizado no Autódromo de Interlagos.

A proposta foi criar uma página temática sobre automobilismo, com informações sobre pilotos, classificação e ingressos para o evento. O site possui um visual inspirado nas páginas oficiais de competições de corrida, utilizando cores escuras, detalhes em vermelho e elementos que remetem às pistas.

## Funcionalidades

O site foi dividido em algumas seções principais:

- **Página inicial:** apresenta o GP de São Paulo, com um banner principal, imagem de um carro de corrida e algumas estatísticas do circuito.
- **Grid de pilotos:** exibe quatro pilotos, seus números e respectivas equipes.
- **Classificação:** apresenta uma tabela com posições, pilotos, equipes, vitórias, diferenças e pontuações.
- **Ingressos:** mostra diferentes setores disponíveis, com seus respectivos preços.
- **Formulário de reserva:** permite preencher informações como nome, e-mail, setor desejado, dia, quantidade de ingressos, perfil e recado para o piloto.
- **Navegação:** possui um menu com links que direcionam o visitante para cada seção da página.

## Tecnologias utilizadas

O projeto foi desenvolvido utilizando:

- **HTML5:** responsável pela estrutura e organização do conteúdo.
- **CSS3:** utilizado para estilização, cores, espaçamentos, tabelas, formulários e organização dos elementos.
- **Google Fonts:** utilização da fonte Titillium Web para deixar o visual mais próximo da identidade do automobilismo.

## Design e organização

O visual foi desenvolvido com uma temática esportiva, utilizando principalmente tons de preto, vermelho, branco e cinza.

Também foram utilizados recursos de CSS, como:

- Flexbox e Grid Layout.
- Efeitos de transição nos botões e links.
- Variáveis CSS para organizar as cores.
- Tabelas estilizadas.
- Cards personalizados para os pilotos.
- Media Queries para adaptar o site a diferentes tamanhos de tela.

## Responsividade

O site possui ajustes para dispositivos menores, como celulares e tablets. Nessas telas, o menu, o banner, os cards e o formulário se reorganizam para facilitar a navegação.

## Objetivo do projeto

O objetivo desta atividade foi colocar em prática os conhecimentos adquiridos nas aulas de HTML e CSS, trabalhando com estruturação de páginas, estilização, organização de conteúdo e responsividade.

O projeto também serviu para desenvolver a criatividade e melhorar a familiaridade com a criação de páginas web.
